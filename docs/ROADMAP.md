# Roadmap

## v0.1 — usable local organizer

- Local recursive PDF scan
- Title / author / year / DOI extraction
- Exact and same-DOI duplicate detection
- Smart filename proposal
- Preview + explicit confirmation
- Optional library-level year folders
- CSV / BibTeX library export
- Undo last operation
- Best-effort rollback for failed batches
- Windows installer pipeline

## v0.2 — personal naming rules

- User-editable rename template
- Supported fields: `{year}`, `{author}`, `{title}`, `{doi}`
- Live preview through the existing rename plan
- Remember the last template locally
- One-click restore to the safe default template

## Candidate v0.2.x improvements

- Better author extraction from first-page text
- Side-by-side duplicate comparison
- Better metadata confidence indicators
- More export options

## Later, only after user validation

- Opt-in Crossref metadata enrichment
- Local full-text search index
- Tags / reading status
- Zotero export/import helpers

No destructive auto-deduplication is planned.
